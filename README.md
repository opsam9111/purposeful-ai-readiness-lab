# From Pen and Paper to Purposeful AI

An interactive UTAUT readiness lab for Nigerian secondary-school teachers and school leaders. It combines:

- a UTAUT readiness self-check;
- matched implementation supports;
- a simplified boiling-point-elevation demonstration;
- TPACK and UDL design explanations;
- responsible-AI checkpoints;
- annotated resources and APA references.

## Run locally

Open `dist/index.html` in a modern browser. No build step or server is required.

## GitHub Pages

Copy the files inside `dist/` to the root of a GitHub repository, or configure GitHub Pages to publish from the `dist` folder.

## Accessibility and privacy

The site uses semantic HTML, keyboard-operable controls, visible focus, responsive layouts, reduced-motion support, print styles, text alternatives, and browser text-to-speech. Readiness responses remain in the browser and are not stored.

## Scientific note

The lab uses the idealized relationship `ΔTb = iKbm` for nonvolatile dissolved solutes in water at 1 atm. It is a teaching model, not a substitute for laboratory measurement.
